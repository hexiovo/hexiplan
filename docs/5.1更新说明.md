# HexiPlan 5.1：可定位的反馈表单

新增共享的逐项反馈面板，覆盖四种结构化UI，以及新渲染的兼容报告。所有页面继续采用淡绿色。

可以直接选择章节、截图、图形、验证项、表格行、步骤或条目；填写意见类型、问题类别、具体位置、意见内容和期望调整。支持多条意见的添加、编辑、删除，JSON/Markdown/TXT/Word导出和文字复制。

意见绑定报告版本与哈希，草稿按版本隔离保存。有修改、疑问、阻塞或未保存编辑时，不能生成“通过”确认。预览不能批准真实业务。反馈文件导出与导入均不自动推进工作流。

新增 review_feedback.py 用于版本校验和记录；Astra 仍只规划与分发，记录由Sol执行。记录不会重置修复次数、授予工具权限或批准下一步骤。

保留：原有12套内容模板、4种布局、DOCX导出、截图总览/对比、Humanizer与科研模块、MCP工具准备审批、Sol3/Luna6/浏览器2/高内存1、逐级确认和最多两轮修复。

安装完整新版仍使用新空目录，不覆盖旧版或旧任务。历史预览是样本；实际报告使用新渲染器生成。尚未验证用户的Windows、账户模型或本机Word。详见 docs/5.1验证记录.md。
