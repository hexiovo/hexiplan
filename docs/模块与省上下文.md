# 模块如何生效

本版把新增能力放在 modules/，不是安装 prompt 的正文里，不注册全局 Skill。部署 prompt 只负责安全解压与自检。hexiplan.md 和角色 TOML 提供按需读取入口，详细规则单独保存，避免每个代理读全部文件。

Astra 看 modules/MODULE_ROUTER.md 选择任务类型；Sol/Luna 根据工作包读取对应文件。报告 Sol 在初稿内容确定后做一次语言编辑。普通 coding 不默认调用 Humanizer；中文/英文按段选择，不连续套两套。模块不能启用 HexiPlan，只有用户明确启用后才参与分工。

## 常用的下层命令
```text
python HOME/tools/route_modules.py --role sol-reporter --kind report --language zh
python HOME/tools/route_modules.py --role sol-reporter --kind academic-report --language zh
python HOME/tools/route_modules.py --role sol-researcher --kind literature
python HOME/tools/route_modules.py --role luna --kind ui-implementation
python HOME/tools/route_modules.py --role luna --kind debug
```
输出是所选模块的相对路径和内容哈希。需要正文时加 --print-content。参数 --record-selection --run RUN --owner AGENT_ID 可把选择及版本写入恢复日志；它不证明代理已阅读，也不改变阶段或生成用户批准。

报告初稿和润色稿放在本 run/plans 的不同文件，运行：
```text
python HOME/tools/guard_report.py --before RUN/plans/before.json --after RUN/plans/after.json
```
该工具只允许特定正文/图注字段变化，保护结构、数据表、标题、路径、URL、数字及显式状态；不能自动判断语义等价或检测“AI味”。报告 Sol 仍需对照限定条件、比较关系和主张。有效润色完成后复用 render_report.py 生成不可变版本HTML。

## 节省的是重复工作，不承诺固定额度
框架复用减少重复编写前端；模块按需读取减少无关上下文；已有同版本文献和校验证据复用。不是永久零token缓存，也不能保证多代理总体费用低于单代理。不得为省额度省去关键证据、用户确认或必要环境验证。

## 第三方维护
来源、许可及适配说明在 third_party。包内无上游插件和脚本，不需要 npm/pip/Skills 安装。未来更新来源规则要显式发起，生成新版本并验证冲突；不要运行 git pull 覆盖本包，也不能原地更新用户正在审核的报告。
