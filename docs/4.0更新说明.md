# 4.0 更新说明

## 本次新增

- modules/：11个按需模块，另有简短路由索引及stop-slop参考说明。
- third_party/：9份上游模块的来源记录、5份许可证、适配说明；没有导入上游工具链或整套原文快照。
- tools/route_modules.py：按角色／任务列出要读的规则；可在已初始化任务中显式保存模块版本快照，不改变批准状态。
- tools/guard_report.py：对未提交报告的一次正文编辑，检查保护结构、数字、状态及代码路径等内容。
- MODULES.html：离线模块说明与文件入口，可用原有Word导出。
- prompts/USE_EXISTING_SESSION.txt：已有会话的明确调用范例与模型预检边界。

## 已接入的位置

hexiplan.md、各代理TOML、启动提示词、报告填写说明、状态恢复摘要、安装提示词与离线自检入口均已更新。Astra只读短索引；相关下层按任务读选中的正文规则，不让全体代理每次读完整模块库。

## 没有改变

12套templates/文件与tools/report_assets/文件逐字节保留3.0版本；模型、资源3/6/2/1、用户确认关口、最多两轮修复不变。START_HERE.html只更新工具包说明并加模块入口，未重写CSS或JS。原模板页脚保留其3.0框架版本标识；当前工具包版本以VERSION.txt和package-manifest.json的4.0.0为准。

## 部署方式

这是完整的新版本包，不是覆盖补丁。指定一个新的空目录部署，旧版和旧任务原封不动。不得自行合并runs或覆盖用户修改；跨版本恢复旧任务需要用户另行批准迁移和兼容性检查。
