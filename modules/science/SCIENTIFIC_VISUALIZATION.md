# Scientific Visualization · HexiPlan 适配版

参考：K-Dense-AI/scientific-agent-skills / skills/scientific-visualization/SKILL.md（MIT）。由负责绘图的 Luna 或重要执行 Sol 使用已有环境。Astra 不画图；本文件不授权安装新的绘图库、浏览器或导出工具。

先读实际结构化结果、变量含义/单位、重复测量单位、缺失规则、估计与区间定义及输出目的。与正文/表格使用相同的源数据和分析版本。优先现有可复现的 Python、R 或 MATLAB 绘图工具；已批准样式优先，不擅自改业务 UI 风格。

## 诚实编码
图形类型匹配比较、变化、分布或关系。注明坐标、单位、样本与误差线定义，不能混淆 SD/SE/CI。缺失、零、剔除和插补分开；不为了图好看去除不利点、连过缺失段、修改数据或夸大差异。对数、归一化、平滑、分箱和显示范围有依据并留记录。涉及长度/面积比较时避免误导性的比例；比较图尽量保持可比的轴与颜色尺度。

关键区别不用颜色单独表达，配合标记、线型、直接标签或文字说明；清晰字号、对比度和图例。图题/图注说明数据来源、方法、单位、区间与必要限制，不用装饰性 3D 或无意义复杂布局。AI 示意图不能当统计图；SYNTHETIC_ONLY 数据图显式标记。

## 导出与交付
依据实际使用场景输出显示图和必要的高质量版本；具体期刊规格需核对其当前官方要求，未知时标为通用输出，不宣称自动投稿合规。HTML 嵌图沿用 PNG/JPEG，底层数据、生成脚本和必要矢量输出留在 evidence/results，不反复让报告代理重画。

检查真实导出图而不只看绘图命令成功：无裁切、单位和文字正确、比较关系可读。复杂图提供简要替代文字/数据表。填写既有 academic/acceptance 模板的 figure/gallery 字段，保留 APA 风格图号、图题和注释，不改 HTML 前端或 DOCX 导出。

图像调整保留原始文件及处理记录；隐私脱敏针对必要信息，不能选择性修改科学图像。只验证本次图形与源数据对应，不追加无关统计分析。
