# HexiPlan 5.0

这次新增的是四种真实结构，不是四种配色。全部淡绿色；用户尚未选定正式默认，预览不是审批。

## 使用
打开 UI_OPTIONS.html 比较结构：A 分区工作台，B 连续文档，C 逐步向导，D 截图审阅台。选定后复制页面的选择文本给 Codex，记录到需求确认；不用再次生成页面代码。

## 按需渲染
```text
python -B tools/render_layout.py --data INPUT.json --out NEW_REPORT_DIR --layout workbench
```
`--layout` 支持 workbench / document / wizard / evidence。沿用12种内容模板，输入不适用内容如实说明；不会把所展示样例固定成业务开发步骤。HTML自包含；所有分页/标签只用于阅读。全文仍可搜索、打印和导出Word，证据审阅提供完整报告。示例截图均标为设计原型，不是已实现功能。

## 工具使用
extensions/TOOL_POLICY.md 已作为工作规则合并。具体MCP清单为空，没有下载、安装或启动任何MCP。按 G2 可见工具清单一次审批，批准范围内使用，变化则重新确认。check_tool_plan.py 仅作离线完整性检查与已批准方案匹配，不是安全沙箱或自动安装器。具体运行能力以用户机器实际预检为准。

## 保持不变
Astra规划，Sol最多3个，Luna最多6个，浏览器2个，高内存1个；逐关确认、最多两轮修复、恢复记录及模块按需读取不变。旧12套内容模板与渲染核心原样保留，以新结构渲染器附加实现；不会覆盖旧包或旧报告。安装新版仍用新空目录。

## 边界
HTML按钮仅复制意见/选择文本，不能认证用户或推进工作流。资源配额与工具计划是协作检查，不拦截绕过脚本的系统调用。模型、MCP及Word仍需用户实机检查。
